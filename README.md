# CSIT214_Assignment

## Instruction guide to run the application

## Backend Setup 

**Required software**: NODEJS v20+

Install required dependencies and libraries using `npm i` inside the `backend` folder, and use `npm start` to run the backend service. The backend by default uses port 3000.

---
## Frontend Setup 

**Required software**: NODEJS v20+, JAVA v21 strictly, (optional) Andorid Studio with an emulator setup for Android app testing/development/compilation.

Install the Expo framework and dependices using `npm i` insdie the `frontend` folder, and use `npm run web` to run the frontend for the browser. Prerferably run the frontend after running the backend service to ensure functionality of elements in the frontend to behave correctly.
